# Gonitwa – wersja przeglądarkowa

Chowany na prawdziwej mapie (GPS): łowcy kontra uciekinierzy.

**Zagraj:** https://jestewole-ops.github.io/gonitwa/

- iPhone: otwórz link w Safari → Udostępnij → „Do ekranu początkowego”.
- Gra łączy się z graczami z aplikacji na Androida – wystarczy ten sam 6-znakowy kod.
- Podczas rundy trzymaj stronę otwartą i ekran włączony (po zablokowaniu telefonu przeglądarka przestaje wysyłać pozycję).

Plik `index.html` jest generowany przez `tools/build_web.py` z projektu Android Studio – nie edytuj go ręcznie.
