# Gonitwa – wersja w przeglądarce

Gra terenowa z GPS: tropiciele kontra zbiegowie.

**Zagraj:** https://jestewole-ops.github.io/gonitwa/

- iPhone: otwórz link w Safari → Udostępnij → „Do ekranu początkowego”.
- Gra łączy się z graczami z aplikacji na Androida – wystarczy ten sam 8-znakowy kod.
- Podczas rundy trzymaj stronę otwartą i ekran włączony (po zablokowaniu telefonu przeglądarka przestaje podawać pozycję).
- [Regulamin](legal/regulamin.html) · [Polityka prywatności](legal/prywatnosc.html)

Mapa: OpenFreeMap © OpenMapTiles, dane © współtwórcy OpenStreetMap (ODbL).

Plik `index.html` jest generowany przez `tools/build_web.py` z projektu Android Studio – nie edytuj go ręcznie.
